# FlowForge

> Async API workflow testing and load analysis platform with per-endpoint Z-score anomaly detection and CI/CD integration.

## Overview
A composable async pipeline engine for testing multi-step API workflows under load. Profiles per-endpoint latency, flags anomalies with Z-score detection, and integrates directly into CI/CD.

## Technical Details
- **Engine**: Async pipeline for composable API workflow execution
- **Anomaly detection**: Z-score on per-endpoint latency profiles
- **Load runner**: Configurable concurrency + ramp profiles
- **CI/CD**: GitHub Actions integration out of the box
- **Used in**: VIT Vellore Software Engineering Lab (BCSE301P)

## Stack
`Python` `FastAPI` `asyncio` `GitHub Actions`
